HSK1 Reset Master v2.1 - Audio Fix

IMPORTANT
1. Keep index.html and the audio/ folder together.

5. The visible SHZ track titles inside the website are unchanged.

Recommended local test:
- Unzip the package.
- Open index.html in Chrome/Edge/Safari.
- If a browser blocks local media, serve the folder through a local web server or deploy to GitHub Pages.
